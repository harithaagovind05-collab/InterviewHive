# InterviewHive

## About

InterviewHive is a placement preparation platform designed to help students prepare for technical interviews in one place.

## Version 1 Features

- User Registration
- User Login
- Coding Progress Tracker
- Interview Question Tracker
- Daily Progress

## Future Features

- AI Resume Analyzer
- AI Mock Interview
- Personalized Roadmap
- Company-wise Interview Experiences
- Placement Analytics
